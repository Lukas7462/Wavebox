# 🎵 WAVEBOX

Dein persönlicher Musik-Streaming-Player mit YouTube Music Integration.

## ⚡ 1-Klick Deploy auf Railway (kostenlos)

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/Lukas7462/Wavebox)

### Deployment Schritte:
1. Klicke den Button oben
2. Mit GitHub anmelden (kostenlos)
3. **"Deploy Now"** klicken
4. Warten bis Build fertig ist (~3 Min)
5. Unter **Settings → Volumes** ein Volume bei `/data` hinzufügen (für dauerhafte Speicherung)
6. Fertig! Du bekommst eine URL wie `wavebox-xxx.up.railway.app`

> Railway gibt **$5 Gratis-Credits/Monat** – das reicht für diese App locker aus.

## Features

- 🎵 **YouTube Music Suche** – Songs, Covers & Alben direkt streamen
- 🎯 **Spotlight-Filter** – Suche findet nur Songs mit gleicher Länge (±1-3s)
- 🚫 **Nur Lieder** – Musikvideos, Konzerte, Full-Albums werden gefiltert
- 🎤 **Sprachsteuerung** – "Hey Wavebox" Wake-Word
- 📝 **Lyrics** – Mit Timing-Editor
- 🤖 **KI-Lyrics** – Per OpenRouter API (kostenloser Key auf openrouter.ai)
- ❤️ **Likes, Playlisten, Künstler-Profile**
